# CURL Commands for MERN Developers

`curl` is a command-line tool used to send HTTP requests and test APIs.

## 1. GET — Fetch Data
```bash
curl -X GET http://localhost:5000/users
```

## 2. POST — Send Data with JWT Authorization
```bash
curl -X POST http://localhost:5000/users -H "Content-Type: application/json" -H "Authorization: Bearer YOUR_JWT_TOKEN" -d "{\"name\":\"Abhishek\"}"
```

## 3. PUT — Update Data
```bash
curl -X PUT http://localhost:5000/users/1 -H "Content-Type: application/json" -d "{\"name\":\"Updated Name\"}"
```

## 4. PATCH — Update Specific Data
```bash
curl -X PATCH http://localhost:5000/users/1 -H "Content-Type: application/json" -d "{\"name\":\"New Name\"}"
```

## 5. DELETE — Delete Data
```bash
curl -X DELETE http://localhost:5000/users/1
```

## Meaning of Important Options

| Option | Meaning |
|---|---|
| `curl` | Command-line tool for sending HTTP requests |
| `-X` | Specifies the HTTP request method; short for `--request` |
| `-H` | Adds an HTTP header |
| `-d` | Sends data in the request body |
| `GET` | Fetches data |
| `POST` | Creates or submits data |
| `PUT` | Replaces or updates a resource |
| `PATCH` | Partially updates a resource |
| `DELETE` | Deletes a resource |
| `Authorization: Bearer TOKEN` | Sends a JWT for authentication |
| `Content-Type: application/json` | Indicates that the request body contains JSON |

## Important Notes

1. `curl URL` uses GET by default, so `-X GET` is optional.
2. `-X` can be used with GET, POST, PUT, PATCH, and DELETE.
3. `-d` automatically selects POST unless you explicitly specify a different method.
4. Replace `YOUR_JWT_TOKEN` with a valid token when testing protected routes.
5. These commands work only when the corresponding Express routes exist in your backend.
